# План монтажа — clip1, кандидат №1

**Типы:** неожиданное событие (основной) + крик/реакция + смешная фраза.
**Итог:** ~15,2 сек, 1080×1920, 60 fps. Чистого материала мало (говорит он только 8,7–14,4), поэтому длину добираем слоу-мо пика, стоп-кадром и концовкой «8 HP, раунд наш».

**Раскладка:** вебка 709×510 → 1080×777 (~40% высоты, соотношение сторон почти совпадает, обрезки нет). Игра 900×1090 → 1080×1143, кроп по центру (сверху/снизу срезается ~80 px, HUD со счётом остаётся частично).
**Шрифт:** выбери по `frames/font_options.png` (моя рекомендация — 2, Russo One).
**Звук:** голос и игра разделены через UVR MDX-Net. Под голосом игра −6 dB, итог −14 LUFS. Звучит оригинальный звук.
